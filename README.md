# Garibook Homepage Clone

A responsive recreation of the [Garibook](https://garibook.com) homepage, built with React and Vite for the Frontend Intern assessment at Endow Tech.

## Tech Stack

- React 19
- Vite
- Plain CSS (custom properties, CSS Grid & Flexbox, no UI framework)

## Sections Implemented

- Sticky header with navigation and a mobile hamburger menu
- Hero section with a tabbed (Car Rental / Airport Rental) booking form
- Stats banner ("From Everyday Rides to Meaningful Journeys")
- Services section with filter tabs and a service card grid
- "Freedom in Every Journey" step cards
- "More Than Miles" feature cards
- App download / Smart Driver dual CTA
- Featured-in-news grid
- Passenger testimonials
- Blog preview grid
- App download banner
- Footer with sitemap, contact info, and legal links

## Getting Started

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173`.

To create a production build:

```bash
npm run build
npm run preview
```

## Notes

- Layout, copy, and structure were recreated by studying the live site at garibook.com; all icons/illustrations are original (emoji/CSS/SVG), not copied assets, since the goal was to rebuild the UI from scratch.
- Fully responsive from mobile (375px) to desktop.
